# Krish Gupta — Portfolio

Premium Next.js 14 portfolio for Krish Gupta.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Included

- Stocker is the first and featured/main project.
- InvoiceFlow is presented as a SaaS/full-stack project.
- Job Application Tracker is presented as an AI/cloud-native project.
- No fabricated business metrics are used in project previews.
- Project previews describe real functionality rather than claiming real usage numbers.
- GitHub, LinkedIn and the Stocker live demo are wired to the supplied URLs.
- Resume is included at `public/resume.pdf`.

## Before deploying

Run:

```bash
npm run build
```

The only remaining links you may want to add later are a dedicated Stocker GitHub repository URL if it differs from the supplied profile URL, and a live deployment URL for InvoiceFlow / Job Application Tracker if you deploy them.
